# Эмулятор командной строки UNIX-подобной ОС

Практическая работа №3, вариант №3. Консольный эмулятор оболочки
UNIX-подобной ОС. В этом коммите готова первая часть работы — каркас
приложения: интерактивный REPL (этап 1) и конфигурация через параметры
командной строки со стартовыми скриптами (этап 2).

Виртуальная файловая система и команды работы с ней появятся в следующих
коммитах; пока `ls` и `cd` — заглушки, которые печатают своё имя и аргументы.

## Сборка

Проект собирается CMake на Linux и Windows (GCC, Clang, MSVC, MinGW).
Требуется компилятор с поддержкой C++17.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Linux/macOS: исполняемый файл `build/bin/emu`.
Windows (Visual Studio): `build/bin/Release/emu.exe` (или `build/bin/emu.exe`
для MinGW/Ninja).

## Запуск

```bash
./build/bin/emu
```

```
Эмулятор командной строки UNIX-подобной ОС, этап 2.
Введите help для списка команд, exit — для выхода.
vfs:/$ ls /
ls: заглушка, аргументов: 1
  аргумент 1: "/"
vfs:/$ exit
```

## Команды текущего этапа

| Команда            | Описание                                            |
|--------------------|-----------------------------------------------------|
| `ls [аргументы...]`| заглушка: печатает имя команды и все аргументы      |
| `cd [аргументы...]`| заглушка: печатает имя команды и все аргументы      |
| `exit [код]`       | выход с кодом 0..255                                |
| `help`             | справка                                             |

Приглашение содержит имя VFS (`vfs:/$ `). Строка разбирается на аргументы с
поддержкой одинарных и двойных кавычек и экранирования `\`; при ошибке
разбора печатается позиция, а эмулятор продолжает работу.

```
vfs:/$ ls -l "файл с пробелами" 'ещё аргумент'
ls: заглушка, аргументов: 3
  аргумент 1: "-l"
  аргумент 2: "файл с пробелами"
  аргумент 3: "ещё аргумент"
vfs:/$ ls "незакрытая
emu: ошибка разбора строки: не закрыта двойная кавычка (позиция 4)
```

## Параметры командной строки

```
emu [параметры]

--vfs <путь>       путь к физическому расположению VFS
--script <путь>    стартовый скрипт с командами эмулятора
-i, --interactive  остаться в интерактивном режиме после скрипта
--debug            отладочный вывод параметров (по умолчанию включён)
--no-debug         отключить отладочный вывод
-h, --help         справка
-V, --version      версия
```

Допустимы обе формы: `--vfs путь` и `--vfs=путь`. При запуске печатаются все
заданные параметры:

```
$ ./build/bin/emu --vfs README.md --script scripts/stage2.emu
[config] отладочный вывод параметров запуска:
[config]   путь к VFS:       "README.md"
[config]   стартовый скрипт: "scripts/stage2.emu"
[config]   режим работы:     пакетный (только скрипт)
[config]   отладочный вывод: включён
[config]   версия:           0.2.0
[config]   VFS (абс. путь):  /home/user/pr_3/README.md
[config]   скрипт (абс. путь): /home/user/pr_3/scripts/stage2.emu
README:/$ ls /
ls: заглушка, аргументов: 1
  аргумент 1: "/"
```

На этом этапе путь к VFS только принимается и выводится: файл ещё не
читается, а имя в приглашении берётся из имени файла.

Некорректные параметры завершают программу с кодом 2, отсутствие стартового
скрипта — с кодом 1.

## Стартовые скрипты

Скрипт выполняется построчно. Строки, начинающиеся с `#`, — комментарии,
пустые строки пропускаются. Каждая выполняемая строка печатается вместе с
приглашением, поэтому на экране получается диалог, как при ручном вводе:

```
$ ./build/bin/emu --script scripts/stage2.emu --no-debug
vfs:/$ ls /
ls: заглушка, аргументов: 1
  аргумент 1: "/"
vfs:/$ ls / # это комментарий, в аргументы не попадёт
ls: заглушка, аргументов: 1
  аргумент 1: "/"
vfs:/$ ls "незакрытая кавычка
[script] scripts/stage2.emu:23: ошибка разбора: не закрыта двойная кавычка (позиция 4)
vfs:/$ unknown_command --flag
emu: команда не найдена: unknown_command (для списка команд введите help)
[script] scripts/stage2.emu:26: команда завершилась с кодом 127
vfs:/$ exit 0
```

Ошибка в скрипте не прерывает его выполнение, но печатается с именем файла и
номером строки.

| Файл                                    | Содержимое                                       |

| `scripts/os/windows/check_cli.bat`      | те же проверки для Windows                       |
| `scripts/os/windows/demo_stage2.bat`    | демонстрация для Windows                         |

```bash
bash scripts/os/linux/check_cli.sh
# ...
# Итого: успешно 15, провалено 0
```
