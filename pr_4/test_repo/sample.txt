# Пример файла тестового репозитория (этап 3).
#
# Формат: "ПАКЕТ -> ЗАВИСИМОСТИ" через запятую.
# Имена пакетов — заглавные латинские буквы.
# Строки с # и пустые строки игнорируются.
#
#   A -> B, C
#   B -> D
#   C -> D, E
#   D -> F
#   E -> F
#   F ->
#
# Граф без циклов:
A -> B, C
B -> D
C -> D, E
D -> F
E -> F
F ->

# Граф с циклом:
X -> Y
Y -> Z
Z -> X

# Самозависимость:
S -> S, T
T ->
